# Classes whose shape this mod needs to know, one per line, with either a line
# cap or a word to grep for. CI prints their public members on every run and the
# answers get folded into the code, at which point the line is deleted.
#
# This file exists because Minecraft 26 ships unobfuscated but undocumented:
# the names are all there in the jar, and guessing at them one CI round trip at
# a time is what made the first port take a day. Asking the jar directly costs
# one step of a build that was running anyway.
#
# Answered so far and now in use:
#   GuiGraphicsExtractor.fill(x1,y1,x2,y2,argb)  - what a preview draws with
#   GuiGraphicsExtractor.text(Font,Component,x,y,argb), centeredText, outline
#   Button.builder(Component, OnPress)
#   ClientLevel.entitiesForRendering() -> Iterable<Entity>  - the hostile scan
#   Entity.fallDistance is a public double
#   Fabric's world render events live under rendering.v1.level, not rendering.v1
#   Screen has no render() at all: it is extractRenderState(GuiGraphicsExtractor,
#     mouseX, mouseY, partialTick). Screens describe what to draw and the game
#     draws it later.
#   Screen.addRenderableWidget(T) is unchanged
#   world.entity.monster.Monster is the base class of everything that attacks
