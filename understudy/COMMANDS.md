# Understudy commands

## Building

| | |
|---|---|
| `/build` | open the menu: pick a design, size and materials |
| `/build <name> [size]` | hut, house, tower, storage, study or manor |
| `/build cancel` | drop the site you are placing |
| `/build stop` | stop a build that is under way |
| `/build imports` | where to drop schematics and models |
| `/plan <name> [size]` | what it would cost, without building anything |

## Placing a build

| | |
|---|---|
| `tap crouch` | put one corner of the plot where you look |
| `look around` | drag the far corner; the design resizes to fit |
| `R` | turn it a quarter |
| `Page Up / Page Down` | raise or lower it off the ground |
| `Enter` | confirm the square, then again to build |

## Fetching and making

| | |
|---|---|
| `/get <item> [n]` | go and get it, however that has to happen |
| `/get iron_ingot+coal 8` | several at once, planned as one trip |
| `/sort` | put your things in the chests they belong in |
| `/sort all` | the same, including the kit you carry |
| `/enchant [item]` | at a table with its fifteen shelves |
| `/travel <x> <y> <z>` | walk there |
| `/travel stop` | stop walking |

## Running it

| | |
|---|---|
| `/understudy` | this list |
| `/understudy help [topic]` | one section of it: build, site, get, run, look, fix |
| `/understudy stop` | stop everything, now |
| `/understudy pause` | hold it there, keeping the plan |
| `/understudy resume` | carry on from where it was |
| `/understudy status` | what it is doing this second |
| `/understudy why` | what it thinks is going on, and why |
| `/understudy auto [item] [n]` | decide for itself what to do next |
| `/understudy auto off` | stop deciding for itself |
| `/understudy speed [how]` | steady, brisk, or flat out — which is visibly a mod |
| `/project [which]` | an objective: kit, camp, base, enchanter |

## Looking at it

| | |
|---|---|
| `/panel` | a control panel in your browser |
| `/panel network` | the same, reachable from your phone |
| `/panel open` | open the browser at it again |
| `/panel off` | shut the panel down |
| `/understudy hud` | turn the line above the hotbar on or off |
| `/understudy atlas` | everywhere it has seen anything |
| `/understudy timing` | where the time actually went |
| `/understudy profile` | what it has learned about how you play |

## When something is wrong

| | |
|---|---|
| `/understudy test` | check every part and say what is broken |
| `/understudy chatfix` | repair settings that hide or squash chat |

## Taking the controls

- Move, look around or open a chest and it lets go at once, keeping the plan.
- It picks the work back up after ten seconds of you doing nothing at all.
